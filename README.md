# Leitor RPI

Leitor gratuito da **Revista da Propriedade Industrial (RPI)**, desenvolvido para facilitar a consulta e localização de publicações do Instituto Nacional da Propriedade Industrial (INPI).

## Sobre o projeto

A ferramenta permite consultar as publicações da RPI de forma rápida e prática, facilitando a localização de processos e informações relacionadas à propriedade industrial.

O projeto foi desenvolvido com foco em simplicidade, acessibilidade e facilidade de consulta, especialmente para profissionais que acompanham processos perante o INPI.

## Recursos

* Consulta das edições da RPI
* Pesquisa e localização de informações
* Interface simples e intuitiva
* Acesso gratuito
* Não exige cadastro
* Não armazena dados dos usuários

## Privacidade

O projeto não armazena documentos, informações de processos ou dados pessoais dos usuários. A ferramenta foi desenvolvida para permitir a consulta das publicações sem a necessidade de criação de uma conta ou fornecimento de informações pessoais.

## Tecnologia

O projeto utiliza tecnologias web e scripts desenvolvidos em Python para processamento e organização das informações da RPI.

## Aviso

Esta é uma ferramenta independente e **não possui vínculo oficial com o INPI**.

As informações disponibilizadas têm caráter exclusivamen
